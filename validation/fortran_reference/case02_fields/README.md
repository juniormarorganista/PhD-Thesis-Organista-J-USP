# Case 02 fields and source terms Fortran reference

This directory contains a standalone Fortran program that exports reference
values for the MMS Case 02 exact fields and source terms:

```text
u, v, wz, psi, txx, txy, tyy, tfwz, tfTxx, tfTxy, tfTyy
```

The expressions mirror the original routines:

```text
src/fortran_original/4Order_LPOG_Euler/case_02.f::exact_solutions_case_02(t)
src/fortran_original/4Order_LPOG_Euler/case_02.f::source_term_case_02(t)
```

`boundaries_condictions_case_02` is not separately exported, for the same
reason as Case 01 (see `validation/fortran_reference/case01_fields/README.md`).

`u`, `v`, `wz`, `psi` are algebraically identical to Case 01. The polymeric
stress field is a quadratic polynomial in `x` and `y`
(`(a1 + a2 x + a3 x^2)(b1 + b2 y + b3 y^2)`), unlike Case 01's spatially
uniform stress or Case 12's trigonometric shape factors.

Default parameters (`Rey=1`, `Wi=1`, `beta=0.5`, `epsilon=0`, `xi=0`,
`alphaG=0`, `at=0`, all `a`/`b` coefficients `=1`) match
`Case02Parameters`/`Case02SourceTermParameters` in the Python port.

The original Fortran thesis code is not modified.

## Transcription method

The four source-term expressions in this file were generated by a
mechanical script that strips the Fortran77 fixed-form continuation prefix
and replaces `dexp`/`dlog` with `exp`/`log`, preserving every parenthesis
of the original character-for-character (rather than manually retyping the
expression). This caught one transcription slip during development: the
first hand-written version of `tftxy_case02` had an extra closing
parenthesis, which the mechanical re-extraction (and the resulting
parenthesis-balance check against the original) immediately revealed.

## Compile

```powershell
gfortran -O2 -std=f2008 `
  validation\fortran_reference\case02_fields\case02_fields_reference.f90 `
  -o validation\fortran_reference\case02_fields\case02_fields_reference.exe
```

## Generate reference CSV

```powershell
.\validation\fortran_reference\case02_fields\case02_fields_reference.exe `
  validation\reference_data\case02_fields_5x5_default.csv 5 5

.\validation\fortran_reference\case02_fields\case02_fields_reference.exe `
  validation\reference_data\case02_fields_9x9_default.csv 9 9
```
