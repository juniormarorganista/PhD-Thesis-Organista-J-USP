# Case 06 fields and source terms Fortran reference

This directory contains a standalone Fortran program that exports reference
values for the MMS Case 06 exact fields and source terms:

```text
u, v, wz, psi, txx, txy, tyy, tfwz, tfTxx, tfTxy, tfTyy
```

The expressions mirror the original routines:

```text
src/fortran_original/4Order_LPOG_Euler/case_06.f::exact_solutions_case_06(t)
src/fortran_original/4Order_LPOG_Euler/case_06.f::source_term_case_06(t)
```

`boundaries_condictions_case_06` is not separately exported, for the same
reason as Case 01 (see `validation/fortran_reference/case01_fields/README.md`).

`u`, `v`, `wz`, `psi` follow the same Taylor-Green-vortex trigonometric
ansatz as Cases 04 and 05. The polymeric stress field uses the same
trigonometric ansatz as Case 03 (and Case 12).

Default parameters (`Rey=1`, `Wi=1`, `beta=0.5`, `epsilon=0`, `xi=0`,
`alphaG=0`, `at=0`, all `a`/`b` coefficients `=1`) match
`Case06Parameters`/`Case06SourceTermParameters` in the Python port.

The original Fortran thesis code is not modified.

## Transcription method

Generated by the established mechanical scripts. Every term -- including
the comparatively compact `tfwz` -- was copied verbatim into both this
reference and `source_terms/case_06.py`, per the discipline established
after Case 04's sign error. Both transcriptions agreed at machine
precision on the first attempt.

## Compile

```powershell
gfortran -O2 -std=f2008 `
  validation\fortran_reference\case06_fields\case06_fields_reference.f90 `
  -o validation\fortran_reference\case06_fields\case06_fields_reference.exe
```

## Generate reference CSV

```powershell
.\validation\fortran_reference\case06_fields\case06_fields_reference.exe `
  validation\reference_data\case06_fields_5x5_default.csv 5 5

.\validation\fortran_reference\case06_fields\case06_fields_reference.exe `
  validation\reference_data\case06_fields_9x9_default.csv 9 9
```
