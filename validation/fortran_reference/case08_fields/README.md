# Case 08 fields and source terms Fortran reference

This directory contains a standalone Fortran program that exports reference
values for the MMS Case 08 exact fields and source terms:

```text
u, v, wz, psi, txx, txy, tyy, tfwz, tfTxx, tfTxy, tfTyy
```

The expressions mirror the original routines:

```text
src/fortran_original/4Order_LPOG_Euler/case_08.f::exact_solutions_case_08(t)
src/fortran_original/4Order_LPOG_Euler/case_08.f::source_term_case_08(t)
```

`boundaries_condictions_case_08` is not separately exported, for the same
reason as Case 01 (see `validation/fortran_reference/case01_fields/README.md`).

Like Case 07, `u`, `v`, `wz`, `psi` decay in time through a hyperbolic
tangent (`1 - tanh(4 - 8*at*t)`) rather than `exp(-at*t)`, but with a
purely polynomial spatial structure (no trigonometric factors). The
polymeric stress field is a quadratic polynomial in `x` and `y`, the same
ansatz as Case 02.

Default parameters (`Rey=1`, `Wi=1`, `beta=0.5`, `epsilon=0`, `xi=0`,
`alphaG=0`, `at=0`, all `a`/`b` coefficients `=1`) match
`Case08Parameters`/`Case08SourceTermParameters` in the Python port.

The original Fortran thesis code is not modified.

## One of the largest ported cases

`case_08.f` is one of the two largest and densest cases (678 lines, only
smaller than Case 09). Its manufactured solution's own nonlinear
convective Jacobian (products of the velocity/vorticity fields with
their derivatives) is written out explicitly in the source terms rather
than vanishing, making every expression substantially larger than Cases
01-07. `tfTxy` alone spans 212 matched parenthesis pairs.

Given this scale, every term in both this reference and
`source_terms/case_08.py` was generated by the mechanical scripts and
assembled programmatically (the Python module's whitespace was then
normalized by `ruff format`, never touching the algebra). No manual
retyping of any expression occurred. Both transcriptions agreed at
machine precision on the first attempt.

## Compile

```powershell
gfortran -O2 -std=f2008 `
  validation\fortran_reference\case08_fields\case08_fields_reference.f90 `
  -o validation\fortran_reference\case08_fields\case08_fields_reference.exe
```

## Generate reference CSV

```powershell
.\validation\fortran_reference\case08_fields\case08_fields_reference.exe `
  validation\reference_data\case08_fields_5x5_default.csv 5 5

.\validation\fortran_reference\case08_fields\case08_fields_reference.exe `
  validation\reference_data\case08_fields_9x9_default.csv 9 9
```
