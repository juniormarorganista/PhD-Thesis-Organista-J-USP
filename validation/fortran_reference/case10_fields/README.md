# Case 10 fields and source terms Fortran reference

This directory contains a standalone Fortran program that exports reference
values for the MMS Case 10 exact fields and source terms:

```text
u, v, wz, psi, txx, txy, tyy, tfwz, tfTxx, tfTxy, tfTyy
```

The expressions mirror the original routines:

```text
src/fortran_original/4Order_LPOG_Euler/case_10.f::exact_solutions_case_10(t)
src/fortran_original/4Order_LPOG_Euler/case_10.f::source_term_case_10(t)
```

`boundaries_condictions_case_10` is not separately exported, for the same
reason as Case 01 (see `validation/fortran_reference/case01_fields/README.md`).
This case's boundary-condition subroutine additionally calls an external
`boundarie_vorticity_cavity_flow` routine for a one-sided wall-vorticity
finite-difference formula; this does not affect the interior exact
fields/source terms ported here.

`u`, `v`, `wz`, `psi` follow the same trigonometric-times-polynomial
ansatz as Case 12 (verified algebraically identical). The polymeric
stress field is spatially uniform, the same ansatz as Case 01.

Default parameters (`Rey=1`, `Wi=1`, `beta=0.5`, `epsilon=0`, `xi=0`,
`alphaG=0`, `at=0`, `c1=1`, `c2=2`, `c3=3`) match
`Case10Parameters`/`Case10SourceTermParameters` in the Python port.

The original Fortran thesis code is not modified.

## Transcription method

Generated by the established mechanical scripts; every term was copied
verbatim into both this reference and `source_terms/case_10.py`, then
the Python module was normalized by `ruff format` (whitespace only).
Both transcriptions agreed at machine precision on the first attempt.

## Compile

```powershell
gfortran -O2 -std=f2008 `
  validation\fortran_reference\case10_fields\case10_fields_reference.f90 `
  -o validation\fortran_reference\case10_fields\case10_fields_reference.exe
```

## Generate reference CSV

```powershell
.\validation\fortran_reference\case10_fields\case10_fields_reference.exe `
  validation\reference_data\case10_fields_5x5_default.csv 5 5

.\validation\fortran_reference\case10_fields\case10_fields_reference.exe `
  validation\reference_data\case10_fields_9x9_default.csv 9 9
```
