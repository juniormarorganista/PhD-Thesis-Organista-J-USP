# Case 05 fields and source terms Fortran reference

This directory contains a standalone Fortran program that exports reference
values for the MMS Case 05 exact fields and source terms:

```text
u, v, wz, psi, txx, txy, tyy, tfwz, tfTxx, tfTxy, tfTyy
```

The expressions mirror the original routines:

```text
src/fortran_original/4Order_LPOG_Euler/case_05.f::exact_solutions_case_05(t)
src/fortran_original/4Order_LPOG_Euler/case_05.f::source_term_case_05(t)
```

`boundaries_condictions_case_05` is not separately exported, for the same
reason as Case 01 (see `validation/fortran_reference/case01_fields/README.md`).

`u`, `v`, `wz`, `psi` follow the same Taylor-Green-vortex trigonometric
ansatz as Case 04. The polymeric stress field is a quadratic polynomial
in `x` and `y`, the same ansatz as Case 02.

Default parameters (`Rey=1`, `Wi=1`, `beta=0.5`, `epsilon=0`, `xi=0`,
`alphaG=0`, `at=0`, all `a`/`b` coefficients `=1`) match
`Case05Parameters`/`Case05SourceTermParameters` in the Python port.

The original Fortran thesis code is not modified.

## Transcription method

Both this reference and the Python port (`source_terms/case_05.py`) were
generated by the mechanical scripts established in Cases 02-04, and
**every** term -- including the comparatively small `tfwz` -- was copied
verbatim rather than retyped, per the lesson learned in Case 04 (a
hand-retyped, visually simple sign was flipped there despite looking
"safe to read at a glance"). The Python port matched this reference at
machine precision on the first attempt.

## Compile

```powershell
gfortran -O2 -std=f2008 `
  validation\fortran_reference\case05_fields\case05_fields_reference.f90 `
  -o validation\fortran_reference\case05_fields\case05_fields_reference.exe
```

## Generate reference CSV

```powershell
.\validation\fortran_reference\case05_fields\case05_fields_reference.exe `
  validation\reference_data\case05_fields_5x5_default.csv 5 5

.\validation\fortran_reference\case05_fields\case05_fields_reference.exe `
  validation\reference_data\case05_fields_9x9_default.csv 9 9
```

## Validate Python against reference

```powershell
python -m pytest tests\test_case05_fields_fortran_reference.py -v
python examples\20_case05_fields_and_source_terms.py
```
