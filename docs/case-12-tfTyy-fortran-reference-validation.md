# MMS Case 12 - `tfTyy` Fortran reference validation

This phase validates the Python port of `tfTyy` against CSV files generated by
an isolated Fortran reference program.

## Run validation

```powershell
python examples\08_validate_case12_tfTyy_reference.py
```

For the 5 x 5 reference:

```powershell
python examples\08_validate_case12_tfTyy_reference.py `
  validation\reference_data\case12_tfTyy_5x5_default.csv
```

Expected result:

```text
passed:        True
```

## Rebuild reference data

```powershell
gfortran -O2 -std=f2008 `
  validation\fortran_reference\case12_tfTyy\case12_tfTyy_reference.f90 `
  -o validation\fortran_reference\case12_tfTyy\case12_tfTyy_reference.exe
```

```powershell
.\validation\fortran_reference\case12_tfTyy\case12_tfTyy_reference.exe `
  validation\reference_data\case12_tfTyy_3x3_default.csv 3 3

.\validation\fortran_reference\case12_tfTyy\case12_tfTyy_reference.exe `
  validation\reference_data\case12_tfTyy_5x5_default.csv 5 5
```
