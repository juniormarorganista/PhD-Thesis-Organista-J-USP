# MMS Case 06 - Python port

This document records the port of the original Fortran file:

```text
src/fortran_original/4Order_LPOG_Euler/case_06.f
```

Case 06 is the sixth of the 13 MMS cases ported after Case 12 (Etapa
14). Its velocity, vorticity and stream-function fields (`u`, `v`, `wz`,
`psi`) follow the same Taylor-Green-vortex trigonometric ansatz as Cases
04 and 05. The polymeric stress field uses the same trigonometric ansatz
as Case 03 (and Case 12), reusing
`mms_viscoelastic.manufactured_solutions.case_12.Case12Coefficients`.
This combination -- Taylor-Green velocity with trigonometric stress --
had not appeared in any prior case (04/05 paired Taylor-Green velocity
with uniform/polynomial stress; 03 paired polynomial velocity with
trigonometric stress).

## Ported components

```text
exact_solutions_case_06(t)   -> manufactured_solutions/case_06.py
source_term_case_06(t)       -> source_terms/case_06.py
boundaries_condictions_case_06(t)  -> not ported separately (see Case 01)
```

## Transcription method

Every term of every Case 06 source function -- including the
comparatively compact `tfwz` (6 top-level terms, 47 matched parenthesis
pairs) -- was generated by the Fortran-to-Python mechanical script and
copied verbatim into `source_terms/case_06.py`, per the discipline
established after Case 04's sign error. The denser `tfTxx`/`tfTyy` (124
and 123 matched parenthesis pairs) and `tfTxy` (118) were split into
top-level additive terms by the script, each pasted unmodified.

The standalone Fortran reference
(`validation/fortran_reference/case06_fields/case06_fields_reference.f90`)
was generated independently by the parallel Fortran-to-Fortran script.
Both transcriptions agreed with each other to machine precision on the
first attempt.

## Python API

```python
from mms_viscoelastic.grids import Grid2D
from mms_viscoelastic.manufactured_solutions import Case06Parameters, evaluate_case_06_exact
from mms_viscoelastic.source_terms import Case06SourceTermParameters, evaluate_case_06_source_terms

grid = Grid2D.from_bounds(nx=33, ny=33)
field = evaluate_case_06_exact(grid, t=0.0, parameters=Case06Parameters())
terms = evaluate_case_06_source_terms(grid, t=0.0, parameters=Case06SourceTermParameters())
```

## Validation status

- All eleven exported quantities validated against an independent
  standalone Fortran reference program
  (`validation/fortran_reference/case06_fields/`), at two grid sizes
  (`5x5`, `9x9`), to `max_abs_error < 1e-10` (observed: machine
  precision on the first attempt).
- Regression tests: `tests/test_case_06_manufactured.py` (shapes, known
  values, identity of `u`/`v`/`wz`/`psi` with Case 04 and `txx`/`txy`/`tyy`
  with Case 03, ML feature table) and
  `tests/test_case06_fields_fortran_reference.py` (Fortran cross-check).
- Example: `python examples/21_case06_fields_and_source_terms.py`.
