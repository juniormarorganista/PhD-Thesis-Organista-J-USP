# MMS Case 10 - Python port

This document records the port of the original Fortran file:

```text
src/fortran_original/4Order_LPOG_Euler/case_10.f
```

Case 10 is the tenth of the 13 MMS cases ported after Case 12 (Etapa
14). Its velocity, vorticity and stream-function fields (`u`, `v`, `wz`,
`psi`) follow the same trigonometric-times-polynomial ansatz as Case 12
(verified algebraically identical, also cross-checked numerically in
`tests/test_case_10_manufactured.py`). The polymeric stress field is
spatially uniform, the same ansatz as Case 01 (verified algebraically
identical too).

This case's `boundaries_condictions_case_10` additionally calls an
external `boundarie_vorticity_cavity_flow` subroutine for a one-sided
finite-difference wall-vorticity boundary condition (the explicit
formula is visible, commented out, in the original source). This is a
boundary-treatment detail outside the scope of the port (boundary
conditions are not ported separately for any case, per the established
convention) and does not affect the interior exact fields or source
terms.

## Ported components

```text
exact_solutions_case_10(t)   -> manufactured_solutions/case_10.py
source_term_case_10(t)       -> source_terms/case_10.py
boundaries_condictions_case_10(t)  -> not ported separately (see Case 01)
```

## Transcription method

Generated by the established mechanical scripts (moderate density: the
largest expression, `tfwz`, spans 58 matched parenthesis pairs, far
below Cases 08/09's scale). Every term was copied verbatim into both the
Fortran reference and `source_terms/case_10.py`, with the Python module
assembled programmatically and normalized by `ruff format`.

## Python API

```python
from mms_viscoelastic.grids import Grid2D
from mms_viscoelastic.manufactured_solutions import Case10Parameters, evaluate_case_10_exact
from mms_viscoelastic.source_terms import Case10SourceTermParameters, evaluate_case_10_source_terms

grid = Grid2D.from_bounds(nx=33, ny=33)
field = evaluate_case_10_exact(grid, t=0.0, parameters=Case10Parameters())
terms = evaluate_case_10_source_terms(grid, t=0.0, parameters=Case10SourceTermParameters())
```

## Validation status

- All eleven exported quantities validated against an independent
  standalone Fortran reference program
  (`validation/fortran_reference/case10_fields/`), at two grid sizes
  (`5x5`, `9x9`), to `max_abs_error < 1e-10` (observed: machine
  precision on the first attempt).
- Regression tests: `tests/test_case_10_manufactured.py` (shapes, known
  values, identity of `txx`/`txy`/`tyy` with Case 01 and `u`/`v`/`wz`/`psi`
  with Case 12, ML feature table) and
  `tests/test_case10_fields_fortran_reference.py` (Fortran cross-check).
- Example: `python examples/25_case10_fields_and_source_terms.py`.
