# Python port of manufactured case 12

This document records the first effective transcription of the Fortran code
into the `mms_viscoelastic` Python library.

## Source file

The Python module was based on the Fortran subroutine:

```text
src/fortran_original/4Order_LPOG_Euler/case_12.f
```

The routine ported in this phase is:

```fortran
exact_solutions_case_12(t)
```

## Python file created

```text
src/mms_viscoelastic/manufactured_solutions/case_12.py
```

## Implemented fields

The `evaluate_case_12_exact` function returns a `Field2D` object with:

- `u`: velocity in the x direction;
- `v`: velocity in the y direction;
- `wz`: vorticity;
- `psi`: streamfunction;
- `txx`: xx normal component of the stress tensor;
- `txy`: xy shear component of the stress tensor;
- `tyy`: yy normal component of the stress tensor.

## Indexing convention

In Fortran, fields are accessed as:

```fortran
field(i,j)
```

In Python/NumPy, the convention adopted is:

```python
field[j, i]
```

i.e. the arrays have shape:

```text
(ny, nx)
```

This is essential to avoid axis swaps in plots and datasets.

## Machine Learning preparation

The example:

```text
examples/02_case12_manufactured_solution.py
```

allows generating a table with columns:

```text
x, y, u, v, psi, wz, txx, txy, tyy
```

This table is the first clean basis for future Machine Learning studies,
such as field regression, neural operators, surrogates or hybrid models.

## Limitation of this phase

The `source_term_case_12(t)` subroutine has not been ported yet. It contains a
very long algebraic expression and must be ported in its own phase, with
separate tests and careful comparison against the data generated by Fortran.
