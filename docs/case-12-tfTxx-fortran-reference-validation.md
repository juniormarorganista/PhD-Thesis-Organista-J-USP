# MMS Case 12 - `tfTxx` Fortran reference validation

This phase validates the Python port of `tfTxx` against CSV files generated by
an isolated Fortran reference program.

## Files

```text
validation/fortran_reference/case12_tfTxx/case12_tfTxx_reference.f90
validation/reference_data/case12_tfTxx_3x3_default.csv
validation/reference_data/case12_tfTxx_5x5_default.csv
src/mms_viscoelastic/validation/source_term_reference.py
examples/06_validate_case12_tfTxx_reference.py
tests/test_case12_tfTxx_fortran_reference.py
```

## Run validation

```powershell
python examples\06_validate_case12_tfTxx_reference.py
```

For the 5 x 5 reference:

```powershell
python examples\06_validate_case12_tfTxx_reference.py `
  validation\reference_data\case12_tfTxx_5x5_default.csv
```

Expected result:

```text
passed:        True
```

## Rebuild reference data

If `gfortran` is installed:

```powershell
gfortran -O2 -std=f2008 `
  validation\fortran_reference\case12_tfTxx\case12_tfTxx_reference.f90 `
  -o validation\fortran_reference\case12_tfTxx\case12_tfTxx_reference.exe
```

Generate references:

```powershell
.\validation\fortran_reference\case12_tfTxx\case12_tfTxx_reference.exe `
  validation\reference_data\case12_tfTxx_3x3_default.csv 3 3

.\validation\fortran_reference\case12_tfTxx\case12_tfTxx_reference.exe `
  validation\reference_data\case12_tfTxx_5x5_default.csv 5 5
```

## Acceptance criterion

The Python implementation passes when:

```text
max_abs_error < 1e-10
max_rel_error < 1e-10
```

for the default reference datasets.
