# MMS Case 11 - Python port

This document records the port of the original Fortran file:

```text
src/fortran_original/4Order_LPOG_Euler/case_11.f
```

Case 11 is the eleventh of the 13 MMS cases ported after Case 12 (Etapa
14). Its velocity, vorticity and stream-function fields (`u`, `v`, `wz`,
`psi`) are algebraically identical to Case 10 (and Case 12, verified
numerically in `tests/test_case_11_manufactured.py`). The polymeric
stress field is a quadratic polynomial in `x` and `y`, the same ansatz
as Case 02 (also verified algebraically identical), reusing
`mms_viscoelastic.manufactured_solutions.case_12.Case12Coefficients`.

## Ported components

```text
exact_solutions_case_11(t)   -> manufactured_solutions/case_11.py
source_term_case_11(t)       -> source_terms/case_11.py
boundaries_condictions_case_11(t)  -> not ported separately (see Case 01)
```

## Transcription method

Combining Case 10's trigonometric-times-polynomial velocity field with
Case 02's quadratic stress ansatz produces source terms denser than
either case alone: `tfTxx` and `tfTyy` each span around 177-179 matched
parenthesis pairs, `tfTxy` around 161, and `tfwz` 64. Every term was
generated by the established mechanical scripts and copied verbatim,
with the Python module assembled programmatically (the same technique
used since Case 08) and normalized only by `ruff format`.

## Python API

```python
from mms_viscoelastic.grids import Grid2D
from mms_viscoelastic.manufactured_solutions import Case11Parameters, evaluate_case_11_exact
from mms_viscoelastic.source_terms import Case11SourceTermParameters, evaluate_case_11_source_terms

grid = Grid2D.from_bounds(nx=33, ny=33)
field = evaluate_case_11_exact(grid, t=0.0, parameters=Case11Parameters())
terms = evaluate_case_11_source_terms(grid, t=0.0, parameters=Case11SourceTermParameters())
```

## Validation status

- All eleven exported quantities validated against an independent
  standalone Fortran reference program
  (`validation/fortran_reference/case11_fields/`), at two grid sizes
  (`5x5`, `9x9`), to `max_abs_error < 1e-10` (observed: machine
  precision on the first attempt).
- Regression tests: `tests/test_case_11_manufactured.py` (shapes, known
  values, identity of `u`/`v`/`wz`/`psi` with Case 10 and `txx`/`txy`/`tyy`
  with Case 02, ML feature table) and
  `tests/test_case11_fields_fortran_reference.py` (Fortran cross-check).
- Example: `python examples/26_case11_fields_and_source_terms.py`.
