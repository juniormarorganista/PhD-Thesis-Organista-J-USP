## GitHub short description

Verification and Python modernization of high-order viscoelastic flow solvers using MMS.

## GitHub longer project pitch

This project preserves the original Fortran and LaTeX sources from a doctoral thesis on high-order numerical verification of incompressible viscoelastic flow solvers. It reorganizes the thesis repository and develops a Python library foundation for manufactured solutions, numerical validation, visualization, dataset generation, and future machine learning workflows.
