## Extended description

Scientific repository associated with the doctoral thesis of Juniormar Organista, dedicated to the numerical verification of high-order codes for incompressible viscoelastic flows via the Method of Manufactured Solutions. The project preserves the original Fortran codes, Mathematica notebooks and LaTeX files, while building a modern Python library for reproducibility, scientific visualization, dataset generation and future integration with machine learning.
