# MMS Case 05 - Python port

This document records the port of the original Fortran file:

```text
src/fortran_original/4Order_LPOG_Euler/case_05.f
```

Case 05 is the fifth of the 13 MMS cases ported after Case 12 (Etapa
14). Its velocity, vorticity and stream-function fields (`u`, `v`, `wz`,
`psi`) follow the same Taylor-Green-vortex trigonometric ansatz as Case
04 (verified: identical formulas, also cross-checked numerically in
`tests/test_case_05_manufactured.py`). The polymeric stress field is a
quadratic polynomial in `x` and `y`, the same ansatz as Case 02, reusing
`mms_viscoelastic.manufactured_solutions.case_12.Case12Coefficients`.

## Ported components

```text
exact_solutions_case_05(t)   -> manufactured_solutions/case_05.py
source_term_case_05(t)       -> source_terms/case_05.py
boundaries_condictions_case_05(t)  -> not ported separately (see Case 01)
```

## Transcription method

Following the lesson from Case 04 -- where a hand-retyped, visually
"simple" sign was flipped despite the expression being short enough to
read at a glance -- every term of every Case 05 source function,
including the comparatively compact `tfwz` (6 top-level terms, 27
matched parenthesis pairs), was generated by the Fortran-to-Python
mechanical script and copied verbatim into `source_terms/case_05.py`,
with no manual retyping at any point. The denser `tfTxx`/`tfTyy` (80
matched parenthesis pairs each) and `tfTxy` (71) were handled the same
way as Case 03: split into top-level additive terms by the script, each
term pasted unmodified.

The standalone Fortran reference
(`validation/fortran_reference/case05_fields/case05_fields_reference.f90`)
was generated independently by the parallel Fortran-to-Fortran script.
Both transcriptions agreed with each other to machine precision on the
first attempt, with no errors to fix -- consistent with the Case 03/05
experience (errors only appeared in Case 04, where the verbatim-copy
discipline was skipped).

## Python API

```python
from mms_viscoelastic.grids import Grid2D
from mms_viscoelastic.manufactured_solutions import Case05Parameters, evaluate_case_05_exact
from mms_viscoelastic.source_terms import Case05SourceTermParameters, evaluate_case_05_source_terms

grid = Grid2D.from_bounds(nx=33, ny=33)
field = evaluate_case_05_exact(grid, t=0.0, parameters=Case05Parameters())
terms = evaluate_case_05_source_terms(grid, t=0.0, parameters=Case05SourceTermParameters())
```

## Validation status

- All eleven exported quantities validated against an independent
  standalone Fortran reference program
  (`validation/fortran_reference/case05_fields/`), at two grid sizes
  (`5x5`, `9x9`), to `max_abs_error < 1e-10` (observed: machine
  precision on the first attempt).
- Regression tests: `tests/test_case_05_manufactured.py` (shapes, known
  values, identity of `u`/`v`/`wz`/`psi` with Case 04, ML feature table)
  and `tests/test_case05_fields_fortran_reference.py` (Fortran cross-check).
- Example: `python examples/20_case05_fields_and_source_terms.py`.
